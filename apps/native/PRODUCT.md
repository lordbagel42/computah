# Computah native

Native Rust Rune frontend for the existing durable Computah core. The approved
June Figma library is visual provenance, not product naming. Product and agent
are Computah. Operate mode: read a conversation, send a request, keep useful
generated surfaces in context, and change the composition without losing recovery.

Pinned direction: AMOLED black, neutral rounded surfaces, fully capsule-rounded
composer, sparse conversation, dim right-aligned Slack ingress, desktop living
panels and narrow-screen conversation. No Tasks/Goals navigation, engine UI or
fake call/microphone support. See ../../ui/IMPORT-PLAN.md and reference PNGs.

All demo places, messages and panels are synthetic. No production endpoint or
credential is bundled. This native adapter does not consume the core's submission
observation SSE, and generated-component delivery is not implemented. v6 presence needs a faithful later native port;
do not substitute generic motion and claim equivalence.

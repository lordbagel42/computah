# Computah operator view

Complementary web operator dashboard, not the native conversation app and not a
Rivet administrator. One trusted operator inspects one server-configured product
scope. The job is to connect visible conversation history to recorded Task calls
and persistent Workers, and understand the limits of that evidence.

The explicit implementation brief fixes read-only behavior, actual CoreSession
history, private access, no engine tokens, no private schema extraction, no second
registry and no model loop. Effect/server contracts remain authoritative.
Generated panels, if added later, must use the existing json-render semantic
catalog; this fixed operator chrome is not a new generative protocol.

Visual authority: `ui/IMPORT-PLAN.md` and inspected `ui/reference/desktop-slack.png`.
Preserve flat AMOLED black, neutral raised surfaces, smooth geometry, high-contrast
text and restrained blue/mint/lavender category colors. Do not reuse the obsolete
letter identity. The operator is examining evidence at a desk, including at night;
the existing dark surfaces are appropriate, not a dashboard starter template.

## Direction contract

THESIS: A conversation-to-execution evidence browser, not a wall of health metrics.
OWN-WORLD: Computah's black canvas, neutral panels, capsule controls and precise
system typography; blue Interaction, lavender Task and mint Worker cues.
STORY: Read the conversation, select a recorded delegation, inspect the scoped
Worker's persisted text and see exactly what is not known.
FIRST VIEWPORT: Compact product header and session controls; scoped conversation
on the left; explicit Interaction → Task → Worker path across the main area;
selectable delegation ledger beside actor evidence. Refresh is the primary action.
FORM: Precisely specified evidence browser within the established source world;
no new visual-world selection or generated concept images.
FINISH: Unreviewed and undocumented is unfinished; inspect desktop/narrow states,
exercise authentication and selection, and document tokens and verification gaps.
